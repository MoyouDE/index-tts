# 固定制包模型目录

正式制包源权重放在本目录的 `checkpoints/`，不是运行缓存或音色输出。该目录下的模型文件不进入 Git；下载地址、固定 revision、字节数和 SHA-256 在上级 `assets.lock.json` 中。

入口以自身文件位置定位目录，不依赖启动时的工作目录。统一验证页与独立制包入口使用同一个默认路径；页面不可编辑。

请使用上级 [启动说明](../README.md) 中的 fetch/verify 命令准备资产，不直接修改模型文件。当前保留完整 GPT、s2mel checkpoint 以提取制包子模块；codec 与 BigVGAN 权重仅用于原有兼容指纹计算，不构建对应生成模型。

长素材的人声检测资产单独放在 `vad/silero-v6.0.onnx`，固定官方 v6.0 revision、字节数和 SHA-256。它在 CPU 按需加载，不参与制包模型兼容指纹，也不提供自动说话人识别。
