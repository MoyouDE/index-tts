# Readest 小说情感标注指南

## 标注单元

每条样本包含 `workId`、上一句、当前句以及 `narration/dialogue` 类型。训练、验证和测试必须按作品切分，同一作品不能跨集合。原文只能来自公版、CC BY/CC0 或拥有明确训练与商业分发授权的内容，并在 `licenseId/source` 留下可审计记录。

每个维度标为 0、0.33、0.67 或 1.0：

- `happy`：喜悦、兴奋、满足。
- `angry`：愤怒、敌意、强烈不满。
- `sad`：明确的悲痛、哀伤或失去。
- `afraid`：恐惧、紧张、威胁感。
- `disgusted`：厌恶、反感、鄙夷。
- `melancholic`：长期、克制、孤独或低沉的忧郁；不要把所有悲伤都标为低落。
- `surprised`：意外、震惊或突然领悟。
- `calm`：主动的从容、安抚、宁静；普通事实性旁白不是 calm。

`intensity` 是该句主动情感的总强度。没有主动情感时八维和 intensity 全为 0，代表让 TTS 使用音色包 `base_emotion`，不能用 calm 代替 neutral/base。

## 质量流程

- 每条样本由两名标注者独立完成；主导情感不一致或任一维度相差超过 0.33 时进入仲裁。
- 12,000 条完整八维样本建议包含八类各约 1,000 条、neutral/base 约 2,000 条、混合/歧义/上下文困难样本约 2,000 条。
- 重点覆盖转折、反讽、悬疑、否定、内心独白和“上一句改变当前句含义”的样本。
- 汇总 JSONL 前保留原始双人标注、仲裁记录和作品授权证明；训练文件只保存仲裁后的最终值。
