用户将验收方式改为“由助手判断候选，人工只判断能否接受”。本次自主选择四段原身份向量等权平均，方法名 `speaker-mean-v1`；理由和不确定性见 `decision.json`。这是可选制包方式，默认仍为 `primary-only-v1`，不宣称普适音质提升。

## 使用

沿用现有环境、固定制包权重及本地工作区，无资产迁移或重新导出生成权重：

```powershell
.venv/Scripts/python.exe -m indextts.validation_web --modules producer,audition --port 7861
```

制包页选择已保存素材，确认片段属于同一人物，每段最长 15 秒；指定主参考，选择“多段身份等权融合”，输入新音色 ID 后生成。所有选中片段参与等权平均，至少两个不同片段；不凑数、不自动删除空白。主参考只编码一次，其余片段仅编码 CAMPPlus 身份向量，再用同一 checkpoint 的说话人投影生成 `speaker_latent`。`prompt_condition`、`ref_mel`、`base_emotion`、`emotion_basis` 保持主参考的结果。

单文件 `VoicePackBuilder.build` 不带新参数时保持旧行为。新增可选 `reference_selection`、`references` 支持固定选择快照。融合输出 schema v3，记录原素材、音轨、选择版本、每个裁剪片段哈希、主参考、版本化方法和精度；六张量 ABI 和源模型／参考编码器指纹规则不变。未知方法、损坏哈希、重复／重叠／超长片段及精度不匹配明确拒绝。旧 schema v1／v2 校验未放宽，历史加载器拒绝 v3。

音色库本地保存主参考和固定裁剪片段。补另一精度使用这些片段，不重新读取可编辑的素材选择；改变选片、主参考或构建方法需新音色 ID。FP32 与 BF16 分别实际编码，禁止 dtype 转换。成功并校验后安装，失败保留原版本。导入的包如果没有参考文件仍不能补制另一精度。
