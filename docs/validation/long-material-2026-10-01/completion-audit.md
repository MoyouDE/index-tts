### 质量门槛的实际结论

“干净主参考”的前提没有得到证实，且用户听到 s002 中混有 BGM。这是本轮样本的有效性限制，不能宣称完成干净素材条件下的音质验收。首轮偏好 V05 和 P02；后续反馈为短句更像本人、长句更自然，没有明确确认 V05 相比 V04 在相似度、清晰度、停顿和稳定性上的整体收益。

因此本轮执行计划中“收益未证明时交付素材工具、实验实现及明确结论”的路径。质量结论为未确认，正式融合、schema v3 和新条件构建方法均保持未启用。它们是用户确认收益后的条件步骤，本轮不伪装成已完成，也不自动改换研究方向、加入降噪或训练模型。

## 保存与复核

源码、实验脚本、资产锁、输入／输出指纹、技术记录、试听反馈和浏览器证明均已保存在当前 IndexTTS 分支的本地提交。大型权重、原始素材、实验张量、WAV 与运行缓存不进入 Git。Readest 主仓库仍为 `master`，既有暂存子模块指针未改动；交接目录未操作，没有推送。

本轮产物复核命令（需要本机现有实验与独立 QA 资产）：

```powershell
$env:PYTHONUTF8 = '1'
.venv/Scripts/python.exe tools/audit_long_material_artifacts.py
```

默认把核对结果写入忽略目录 `outputs/material-artifact-audit.json`，不会生成音频、初始化模型或修改音色库。它校验本轮已保存产物与 Git 中记录的一致性；新设备重新实验应使用主说明中的 prepare/run 命令，不要求不同设备的 WAV 字节哈希与本机相同。可以通过命令参数指定已有实验、记录、QA 音色条目及工作区位置。
